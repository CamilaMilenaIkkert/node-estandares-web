# node-estandares-web
Proyecto con node y npm para el curso Estándares Web

Este proyecto utiliza Node.js con Express, Axios y Nodemon.

Para levantar este proyecto se debe clonar el repositorio de GitHub:

#  git clone <URL-del-repositorio>

Instalar las dependencias mediante:

# npm install

Por último levantar el servidor con:

# npm start

El proyecto podrá ser visualizado en un navegador web a través de http://localhost:3000.
